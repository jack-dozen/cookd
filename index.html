Cara Kerja

Tiga langkah,
satu hidangan

Dari input bahan sampai estimasi biaya, semuanya terintegrasi dalam satu aplikasi desktop yang cepat dan elegan.

1
Masukkan bahan yang kamu punya
Tulis bahan yang ada di kulkas, pisahkan dengan koma. CookD akan mencocokkan dengan ribuan resep di database.
2
Lihat resep dengan Match Score
Setiap resep mendapat skor kecocokan 0–100%. Langsung tahu mana yang paling feasible tanpa beli bahan tambahan.
3
Kalkulasi harga dari 3 toko
Bandingkan harga bahan dari Tokopedia, Alfagift, dan AEON Store secara paralel. Estimasi belanja sebelum ke pasar.

Fitur Unggulan

Semua yang kamu butuhkan,
dalam satu app

Dari pencarian resep berbasis bahan, kalkulasi harga real-time, hingga buku resep personal.

🔍
Finder
Cari Resep dari Bahan Seadanya
Scrape langsung dari Cookpad.com dengan algoritma match score cerdas. Setiap resep diberi nilai 0–100% berdasarkan kecocokan bahan yang kamu punya. Parallel scraping dengan ThreadPoolExecutor untuk kecepatan maksimal.
✅ Mode Lokal 🌐 Mode Scrape 📄 Pagination

Kalkulasi Harga
Bandingkan 3 Toko Sekaligus
Estimasi total biaya belanja bahan dari tiga platform populer secara paralel. Data di-cache 7 hari untuk efisiensi.
Tokopedia Alfagift AEON

My Recipes
Buku Resep Personal
Simpan, edit, dan kelola koleksi resep favorit. Tambahkan catatan personal, foto kustom, dan backup via Import/Export JSON.
⭐
For You
Rekomendasi Berbasis Waktu
Saran resep yang kontekstual — sarapan di pagi hari, makan siang siang hari. Personalisasi otomatis sesuai kebiasaanmu.

Instalasi

Mulai dalam
3 menit

Python 3.12+ dan Google Chrome sudah cukup. Tidak perlu server, tidak perlu konfigurasi database.

BASH
1# Clone repositori
2git clone https://github.com/jack-dozen/cookd
3cd cookd/cookd-app
4
5# Install dependensi
6pip install -r requirements.txt
7
8# Jalankan!
9python main.py
1
Prasyarat: Python 3.12+
Pastikan Python 3.12 atau lebih baru terinstall. Cek dengan python --version
2
Google Chrome wajib ada
Dibutuhkan untuk scraper Alfagift, AEON, dan Tokopedia. ChromeDriver di-auto-install oleh undetected_chromedriver.
3
First Run — Database otomatis dibuat
File data/base.json akan dibuat otomatis. Tidak perlu setup manual.
4
Windows, macOS, dan Linux
Optimized untuk Windows. macOS/Linux butuh Chrome di path default dan permission execute untuk ChromeDriver.
